**Autor:** Juan Diego Restrepo Hernández

## Acerca de este repositorio

Este repositorio reúne actividades, talleres y parciales realizados para la asignatura de Teoría de Aprendizaje de Máquinas. Incluye ejercicios y soluciones en documentos PDF, implementaciones y experimentos en notebooks de Python, y una aplicación interactiva de clasificación de dígitos con MNIST.

El material está organizado por tipo de trabajo:

| Carpeta | Contenido |
|---|---|
| [`actividades/`](./actividades/) | Actividades prácticas y proyectos de implementación. |
| [`parciales/`](./parciales/) | Enunciados, soluciones y código relacionado con los parciales. |
| [`talleres/`](./talleres/) | Talleres de repaso, ejercicios y sus implementaciones. |

## Material disponible

- [Actividad 1: clasificador de números MNIST](./actividades/01_mnist_clasificador/README.md): entrenamiento de una red neuronal convolucional y aplicación Gradio para reconocer dígitos en imágenes.
- [Parcial 1](./parciales/Parcial_1/README.md): regresión en espacios de características, RKHS, MMD y correlación de Pearson.
- [Taller de repaso](./talleres/Taller%20de%20repaso/README.md): clasificación lineal, perceptrón, k-NN y métricas de evaluación.

## Herramientas

Los ejercicios usan Python y notebooks de Jupyter; según el trabajo, también pueden requerir bibliotecas como NumPy, Matplotlib, scikit-learn, TensorFlow, Pillow y Gradio. Revisa el README de cada actividad o taller para conocer sus archivos e indicaciones específicas.
