# Taller de repaso — Teoría de Aprendizaje de Máquina

**Periodo:** 2026-2
**Profesor:** Diego Armando Pérez Rosero
**Autores:** Juan Diego Restrepo Hernandez

## Descripción

Esta carpeta contiene el enunciado de un taller alternativo, el desarrollo del taller de repaso y un notebook con implementaciones en Python. Se trabajan la clasificación lineal y el perceptrón, el algoritmo de k vecinos más cercanos (k-NN) y las métricas para evaluar clasificadores binarios.

## Archivos

- [`Taller_Alternativo_TAM_2026_2.pdf`](./Taller_Alternativo_TAM_2026_2.pdf): enunciado del taller alternativo.
- [`Taller_de_Repaso.pdf`](./Taller_de_Repaso.pdf): solución desarrollada del taller de repaso.
- [`Taller_repaso.ipynb`](./Taller_repaso.ipynb): implementaciones y verificaciones en Python de los puntos programados.

## Contenidos

1. Frontera de decisión, regla de clasificación y actualización del perceptrón.
2. Clasificación mediante k-NN, ejercicios manuales y experimento con `make_moons`.
3. Matriz de confusión y métricas de evaluación de clasificadores binarios.

Para consultar o ejecutar el código, abre el notebook en Jupyter o Google Colab. Puede requerir NumPy, Matplotlib y scikit-learn.
